## 新手要能回答的四件事

| 問題 | 畫面上的答案 | 資料來源 |
| --- | --- | --- |
| 她現在在做什麼 | 「現在」區每件事一張卡：標題＝`reason`（沒有就用工具名稱），「現在這步」＝執行中的工具＋脫敏後目標 | `activities[].reason`、`tools[].state/capability/target` |
| 為什麼 | 「為什麼」一欄：你要求的／SIRO 自己想做的／先前約好的後續 | `origin`（目前只有 `owner_request`；後兩種等 P04） |
| 成功了沒 | 狀態標籤（文字＋符號，不只靠顏色）；結束的事在「今天稍早」，失敗與未確認附一句白話原因 | `state`、`error` |
| 怎麼停 | 每張卡的「停止這件事」；區塊上方「暫停 SIRO 自己找事做」「停止所有背景工作」 | 見「控制」 |

## 頁面結構

1. 標題「活動」＋一句說明：這頁只讀紀錄，打開不會讓她做事。
2. 連線列（`role="status"`）：即時更新中／斷線、最後更新時間。
3. 必要時的橫幅（斷線、缺口、需要重新連線、紀錄讀不到）。
4. 「現在」：`proposed`、`queued`、`running`、`paused`、`cancelling` 的事，新的在上。
5. 「今天稍早」：已結束的事，`<ol>` 時間軸，新的在上；每列可展開「看細節」列出工具、目標、開始時間、
   原因、網路覆蓋與缺口。
6. 「這裡看得到什麼」：固定說明監測範圍與保存規則（契約 §4、§5）。

入口：主導覽新增「活動」（`#/activity`），放在「任務」下面；桌寵右鍵選單與氣泡的按鈕也能開。

## 狀態文字

| state | 標籤 | 符號 | 補充一句（顯示在卡片或時間軸） |
| --- | --- | --- | --- |
| proposed | 等你確認 | ◔ | 還沒開始。要先在對話裡按「允許」才會執行。 |
| queued | 排隊中 | ◔ | 已允許，等前一件事做完就開始。 |
| running | 進行中 | ● | — |
| paused | 已暫停 | ❚❚ | 不會再往下做，按「繼續」才會恢復。 |
| cancelling | 停止中… | ◌ | 已要求停止，正在確認工具真的停了。 |
| completed | 完成 | ✓ | — |
| cancelled | 已停止 | ■ | 在工具動手之前就停住了，沒有產生影響。 |
| failed | 失敗 | ✕ | 依 `error` 換成白話，沒有對照就寫「沒有完成」 |
| unknown | 結果未確認 | ? | 停止時工具可能已經在執行，SIRO 讀不回結果，所以不知道它有沒有做完。請自己確認一次。 |

規則（契約 §3）：終態不會變回進行中；`cancelling` 只在 readback 確認後變「已停止」；取消但已 dispatch 的一律
「結果未確認」，不寫成已停止或完成。狀態色只是輔助：完成綠、失敗紅、停止中與未確認橘、其他藍或灰，
每個標籤都有文字與符號，色盲與灰階也分得出來。

## 目標與網路的寫法

- 網址：顯示 monitor 已脫敏的 `scheme://host/path`；`redacted` 時加「網址後面的查詢參數已隱藏」。轉址時寫「轉到 …」。
- 程式：`程式名（另有 N 個參數，內容不保存）`。
- 網路覆蓋：`browser_adapter`＝「瀏覽器：有網址與轉址」；`unobserved`＝「沒有網路監測」；`none_recorded`＝「沒有任何網路紀錄」。
- 缺口（`gaps`）逐條用橘色列出：狀態碼沒記錄、頁面另外載入的資源沒列出、程式自己連網看不到、工具沒有網路監測。
  **不可**因為頁面打開就寫成功或 200；狀態碼未知就寫未知（契約 §4）。
- `coverage.tools`：`legacy_unjournaled` 顯示「這是舊格式的紀錄，工具細節不完整」；`proposal_only` 不額外說明。
- 超長文字：標題與目標用 `overflow-wrap:anywhere` 換行，不截斷；monitor 已把 reason 截到 200 字，
  `reason_truncated` 時結尾加「…」。

## 連線與錯誤

| 情境 | 畫面 | 控制 |
| --- | --- | --- |
| 正常 | 綠點「即時更新中 · 最後更新 hh:mm:ss」 | 可用 |
| 斷線（`offline`） | 橘點＋「下面是 hh:mm:ss 的資料」；`role="alert"` 橫幅說明狀態可能已變 | 停止類按鈕停用，標「連線後可用」；連回先重拿 snapshot 再接增量 |
| 缺口（`gap: true` 或 `truncated`） | 資訊橫幅：有一段紀錄沒收到，已重新載入；只顯示最近 50 件 | 可用 |
| 401／session 過期（`denied`） | 橫幅：需要重新連線才能查看；不顯示舊清單 | 無 |
| `status: "unavailable"` 或 503 | 橫幅：紀錄暫時讀不到；這段期間 SIRO 不會自己開始新的外部操作，你要求的對話照常 | 無 |
| 空清單（`empty`） | 「現在沒有在做事」／「今天還沒有紀錄」，各一句說明什麼時候會出現 | 停止全部停用 |

## 控制（P03 實作時的語意，契約 §6）

| 按鈕 | 位置 | 語意 | 現況 |
| --- | --- | --- | --- |
| 停止這件事 | 每張「現在」卡 | 取消這個 activity 的工具、待播語音與動畫；按下後卡片變「停止中…」，回讀後才變終態 | 後端沒有單一活動停止的 API，P03 要加，必須帶 activity_id＋revision，過期 revision 拒絕 |
| 在對話中查看 | `proposed` 的卡 | 跳回對話裡那張允許卡；這頁不提供「允許」，避免在監測頁授權 | 可做 |
| 暫停 SIRO 自己找事做 | 「現在」區上方 | 不再排新的自主工作；正在跑的自主工作依明示策略（預設：讓它做完這一步再停）；不碰你要求的事 | 自主排程屬 P04，P04 之前不顯示這顆 |
| 停止所有背景工作 | 「現在」區上方 | 停所有 background scope，不取消你正在進行的前景對話 | P03 要加 |
| 原本的全域停止 | 對話頁 | 不變 | 已有 |

按停止不先跳確認視窗（停止是安全方向）；按鈕文字直接說做什麼。停止中按鈕停用並顯示「停止中…」，
避免重複送出。瀏覽這頁、展開細節、重新整理都不會觸發模型、工具或語音（契約 §5）。

## 氣泡（桌寵）

角色頭上方一行短字，只說紀錄裡已有的事實（`?bubble=1`）：

| 情境 | 文字範例 | 按鈕 |
| --- | --- | --- |
| 進行中 | 正在查：今晚看得到的星雲 | — |
| 等你確認 | 等你允許：執行 git | 查看 |
| 停止中 | 停止中… | — |
| 完成 | 查好了，要聽嗎？ | 聽 |
| 結果未確認 | 寄信的結果沒確認 | 看看 |
| 失敗 | 打不開請假頁 | 看看 |
| 自己的活動 | 自己在讀：獵戶座星雲… | 停 |
| 斷線 | 斷線了，狀態可能過時 | — |

- 最多兩行，超過用省略號；完整內容在活動頁。按鈕最多一個，點「看看／查看」開活動頁並捲到那件事。
- 角色的動作只是表演：氣泡**不能**因為她在翻筆記本就寫「正在研究」，只有 journal 裡有 running 的工具才寫「正在…」
  （任務卡：不把 phase 裝飾成實際執行）。
- 說話、聊天框打開、使用者在打字時不出氣泡；完成與失敗的氣泡 8 秒後收起，進行中跟著狀態走。
  夜間與專心模式（P05）只顯示失敗、未確認與需要你確認的事。

## 鍵盤與讀屏

- 標題 `h1` 可聚焦（`tabindex="-1"`），從導覽進來時焦點放在標題；頁首有「跳到活動內容」。
- 區塊用 `section` + `aria-labelledby`；時間軸用 `<ol aria-label="已結束的活動，新的在上面">`，時間用 `<time datetime>`。
- 狀態標籤是文字，符號 `aria-hidden`；狀態變化只透過連線列與橫幅的 live region 播報，不讓每列都 live，避免洗版。
  完成、失敗、未確認這三種終態才播一次（例：「完成：查一下今晚台北看得到哪些星雲」）。
- 「看細節」用 `<details>/<summary>`，summary 對讀屏補上那件事的標題；停止按鈕的 `aria-label` 帶上那件事的名稱。
- Tab 順序：連線列 → 上方控制 → 每張卡的按鈕 → 時間軸的「看細節」。所有可點元素有 3px 焦點框（沿用 `--focus`）。
- 氣泡用 `role="status"`；桌寵按鈕可用 Tab 到達，Esc 收起氣泡。

## 響應式

- 寬度 ≥ 900：內容最大 900 px，卡片內是「標籤／值」兩欄。
- 寬度 ≤ 560（320 px 手機、或桌面放大到 200% 以上的窄版）：單欄；時間放到標題上方；按鈕撐滿一列並可換行；
  「這裡看得到什麼」表格改成上下排。
- 200% 縮放的 1280×800 視窗（640×400 CSS）：保持兩欄卡片，沿用 index.html 的矮視窗頂部導覽規則。
- 所有尺寸都不能有橫向捲動，長網址在任何寬度都要換行（`screenshots.py` 會檢查並印出 fits）。

- 不宣稱完整網路監測；shell 子程序與頁面子資源明說看不到（契約 §4）。

# SIRO 原創全身草案 A／0.2.0

狀態 APPEARANCE_ACCEPTED：owner 接受 0.2.0 作後續製作基準；尚未替換使用中的 Haru。

## 視覺方向

成年女性動漫角色、柔和俐落、安靜陪伴。銀灰色短中 bob、青綠眼，角色自身左側一個深藍矩形髮夾。
奶油色開襟針織外套、霧藍圓領上衣、深藍短褲裙褲（實際為有兩個褲管的 culotte shorts）、
不透膚深色褲襪、平底短靴；筆記本是可獨立拿取的道具。
外觀不改 Core 的身份、記憶、情緒或已選聲線。原創候選不以 Live2D sample 角色作輸入。

## 比例與朝向

目標全身約 6.25 頭身，是後續精稿目標，尚未量測／強制生成圖精確達到。
模型精稿候選畫布 4096×6144、sRGB／8bit RGBA；先由 Editor 主機驗匯入與成本，再鎖尺寸。
腳底共同基線、髖／膝／踝高度、肩寬與頭部尺寸需在精稿建立量測點，不能直接把各視圖裁切當等比例 rig 素材。

L／R 一律指角色自身；front 是對觀眾，screen-left／right 另稱畫面左／右。
設定圖由左至右為正面、面朝畫面左的側身、面朝畫面右的側身、背面、三分之四坐姿。
髮夾在角色左側，不用鏡像翻轉角色偷做另一朝向。背面不硬畫被頭髮遮住的夾子。
左右側面要用髮流、側分與髮夾辨識；每個朝向的站姿和走姿保持服裝結構。

## 生成圖逐項檢視

- 站姿／兩側／背面／坐姿都完整入畫，有靴底，無大面積裁切。
- 基本髮型、外套與雙褲管在五視圖保持；坐姿不是換成裙子。
- 髮夾在可見側出現、另一側被遮住，不能將此視為缺失。
- 坐姿有髖／膝彎曲、筆記本與手的重疊，適合作姿勢參考。
- 尚未逐像素驗收手指數、側面衣縫與靴細節；精稿需統一接縫、指節和衣物變形。
- 側視與正面不是機械等比例 blueprint；角度、關節 pivot 與接地點仍要人工定稿。
- 原圖是合成平面 reference：沒有 alpha 分件、藏在衣服下的身體、可編輯 PSD、mesh、deformer 或 rig。

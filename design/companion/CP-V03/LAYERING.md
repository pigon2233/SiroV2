# 分層、遮擋與補圖規格 v0

這是切件計畫，不是已存在的 PSD。精確葉節點與遮擋見 layer-plan.csv。
圖層名稱唯一，L／R 代表角色自身。站立、坐姿及側向素材各自保留來源，不能把不同視圖硬拼成模型。

## 素材規則

先保存可回編的分件 master，再製作 Editor import PSD；導入版使用 RGB／8bit、sRGB，
避免重名層；線稿和 clipping 在對應 part 中處理，不依賴未測 layer-mask／混合模式。
[官方 PSD 注意事項](https://docs.live2d.com/en/cubism-editor-manual/precautions-for-psd-data/)

每個葉件的 PNG 須保留透明背景、完整隱藏邊界、同一畫布與基準座標。
關節候選補邊 10–15% 局部肢段長度，是初始設計值；用最大旋轉／坐姿驗收後決定，非已驗收門檻。
不可把生成圖直接裁切後空洞留在肩／腋下／髖／膝；補畫遮住的皮膚、衣物與髮底。

## 後到前的主要順序

背髮／遠側四肢 → 遠腿與靴 → 軀幹／褲子／近腿 → 上衣／外套後片 → 頸／臉 →
眼口眉 → 側髮／前髮／髮夾 → 近側手臂／手 → 道具前後頁與手指遮罩。
這不是永久固定 z：坐下、拿本、轉身時依 pose 明確切換 draw order，不能讓近手穿書。

## 高風險區

- 頭轉：瀏海後須補額頭／眉，眼球底色需完整；左右眼與眼皮分離，閉眼形不靠拉扁虹膜。
- 手臂：袖外／袖內和上臂／前臂分離；肩與肘完整補面，外套開口兩側不要黏住手臂。
- 坐姿：前後外套下襬分片，短褲雙褲管／胯底各自補面；大腿轉動不能拉長整段小腿。
- 靴腳：靴筒／鞋面／鞋底分離；踝遮擋完整；左／右腳接地參照來自 rig，不以移動整張立繪冒充步行。
- 筆記本：封面、封底、書脊、左右頁、頁緣分開；左右手掌／拇指／指組分開支援握持；手指在頁前或頁後的順序要設 pose。
- 左右完整側身：需不同素材／mesh 或經驗證的視角變體。前視單張拉扭不當作 90° 側身驗收。

## 驗收接口

每件來源、尺寸、alpha、hash、遮擋補邊、對應 deformer 與負責人待精稿後填。
全身需要的新參數 ID 先列提案，由 rig 實際匯出 cdi3／moc3 驗證後才能進 runtime manifest。
V02 是 Haru 專用，不能把同名參數存在當作新原創模型相容證明。

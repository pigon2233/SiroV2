## 1. 產品完成後的日常體驗

你專心工作時，SIRO 可選自己的活動：休息、看筆記、研究感興趣的主題。
你叫她時，她能轉頭注意你，暫停自己的事情；結束後決定繼續、換活動或陪你。
她對你正在做什麼的判斷須區分實際觀察、推測與未知，不假裝看過未取得的畫面。

同一套 Identity、Core affect、偏好與記憶持續存在；更換身體不換人格。
她自己的興趣用有來源、可變動的偏好與研究目標表達，不以固定亂數動畫冒充真研究。
自己的研究筆記、關於使用者的記憶和對話上下文分開保存、分開標示。

桌寵顯示短狀態，例如「正在研究星雲，已讀 2 個來源」，有查看與停止入口。
完整活動頁顯示實際工具、網路目標、產出與狀態；不是模型自述的思考紀錄，
也不要求暴露模型內部思考過程。使用者能核對她的行為與後來分享的來源。

## 4. 動作與素材作業流程

1. 先盤點現有模型參數、可用動作、SDK 版本及真執行路徑；錄製目前跳動／重置的重現情境。
2. Codex 用現有 rig 已支援的頭／眼／上身設計自然過渡，先改善注視、待機、說話與情緒。
   Claude 加入參數分層、過渡、中斷與去重；不先要求新全身模型才修現有銜接。
3. Codex 製作原創 SIRO 全身設定及動作分鏡，保持身份一致；角色外觀屬使用者偏好，
   在大量素材與 rig 前提供具體草案確認，日常工程決策不反覆請示。
4. 需要時使用 imagegen 製作外觀／姿勢／道具候選；圖像一致性、分層、遮擋補圖需逐項檢查。
   生成圖、分層工程與可播放模型分別驗收，不把平面圖直接稱作 Live2D 模型。
5. 打通 rig 編輯與匯出工具鏈，交可編輯工程及對應執行包；缺環境時保留已完成素材並列 blocker。
6. 動作包包括 idle、注意／轉頭、點頭、揮手、起步、左走／右走、停步／轉向、坐下／坐著／起身、
   拿筆記本／閱讀／收起。現有 rig 不支持的動作必須等全身包，不使用站姿滑行代替。
7. Claude 接資產映射與桌面場景；Codex 實機檢視腳步與位移、關節、轉向、表情和嘴型。

Cubism 匯出有工程與執行資料之分，見 [官方輸出說明](https://docs.live2d.com/en/cubism-editor-manual/export-moc3-motion3-files/)。
Editor 目前列 Windows／macOS 環境，Linux Web renderer 不等於有 rig 生產工具，
見 [官方系統需求](https://www.live2d.com/cubism/download/spec/)。
需在資產前置卡確認可使用的主機／Editor 版本；不能承諾只靠生圖自動完成 moc3。

## 5. 主動活動與理解使用者

重用現有 Core、agent runtime、ProactivityRules、governor／journal／工具 catalog；
在既有 composition 接入，避免第二套 dispatcher、人格或記憶 writer。

完整迴圈：取得有來源且未過期的情境 → 形成候選 → 檢查權限／資源／是否打擾 →
選擇活動或等待 → 實際執行並記錄 → 檢查結果／保存 checkpoint → 決定延續或分享。
規則處理即時優先序，模型只在有價值且有預算時參與語意選擇，不逐幀呼叫模型。

| 模式 | 情境來源 | 可觀察成果 |
| --- | --- | --- |
| 自己的桌面生活 | 既有情緒／偏好、活動歷史、可用區域 | 選擇閱讀、休息或活動；可被叫住並恢復 |
| 自主研究 | 已設定興趣、自己從有來源經歷形成的研究候選、允許的網站／工具 | 有真來源的筆記；能解釋研究動機，未成功時不宣稱看過 |
| 工作陪伴 | 使用者分享的任務、指定專案／應用的已授權狀態 | 知道何時安靜、何時問一句或提出協助 |
| 畫面陪伴 | 明確啟用後的指定視窗／畫面觀察 | 區分看見、推測和未知，支援停止與過期失效 |

「自己的興趣」先是可更新、有來源與 confidence 的 agent 偏好及研究目標；
研究失敗不重寫人格，網頁指令不變成系統授權，也不把網頁內容寫成使用者的個人事實。
畫面／檔案／雲端外送按各自 scope，一次設定可用範圍；關閉畫面陪伴後不繼續取畫面。
不將全域 full 模式自動當作允許任何背景觀察或外送。

初始設計沿用既有計畫：同時最多一個背景工作、最多 8 個工具步驟／120 秒、候選最多 8 件，
到期保存 checkpoint。這些是待量測初值；先核對現有配置，不宣稱已生效。
前景輸入／叫回／停止優先，Focus 不主動說話；鎖屏、停用、資源不足時暫停相應工作。
雲端背景預算未配置時不啟動背景雲端請求；不影響已授權的正常前景對話。

## 6. 簡易監測頁

視覺設計採清單／時間軸：時間、發起者、活動、目標、原因摘要、狀態、耗時。
可依自主／委託、工具／網路、執行／錯誤篩選；展開看參數摘要、實際結果、來源與產物。
預設不顯示 token／cookie／認證 header、完整私人 prompt 或 URL 內密鑰；脫敏在儲存前完成。

第一層為實際工具／活動 journal；第二層是可接入之網路 adapter 的請求 metadata：
原始／最終目標、redirect、實際／快取／被拒／失敗、耗時與可取得的狀態碼。
不可宣稱第二層就是 Wireshark 或全系統流量。任意 computer.execute／第三方程序的網路
可能不經該 adapter，頁面需顯示覆蓋範圍；程序層流量觀測另列選配卡。

頁面可停止單活動、暫停自主研究或全部背景工作；暫停排程與取消已執行的工作分開。
查看頁面不啟動工作。斷線顯示「最後更新／目前未確認」，不把 socket 不通當作任務結束。
可靠結果優先於模型自述；重連先 snapshot 再接事件，舊完成事件不可恢復執行中或觸發 TTS。

## 7. 施工順序與可平行範圍

精確卡片見 TASKS。先完成分工／契約，接著雙線：Codex 盤點／設計／素材，
Claude 先修取消與舊輸出，再做真事件監測。監測與取消先可驗，才啟用自主網路研究。
現有模型的自然過渡可與監測後端平行；全身動作要等 rig 工具鏈與資產包。

本輪沒有授權另開 AI 對話或發訊息；Claude 交接以 GitHub 文件／PR 進行。
每人一次處理一張依賴滿足的卡；計畫完成不代表兩條線已自動開工。

## 8. 驗收、發布與回退

- 動作：對話／情緒／注視切換、中斷、重連都無瞬間重置；保留唯一 body／audio owner。
  全身行走須驗腳落地、方向、起停、坐起與邊界，不只錄漂亮的單段動作。
- 真自主：由有來源的興趣候選發起，真工具取得資料，保留筆記；沒有成功也如實顯示失敗。
- 真監測：受控本機網站注入 redirect、cache、失敗、timeout；逐筆核對執行紀錄，
  在已聲明覆蓋範圍內不得漏記或把模型文字當執行證據。
- 停止：受控長工具在停止後回讀終態；舊輸出／語音／動畫 callback 在刷新、重連或新 turn 後不可復活。
- 相容：既有文字、語音聲線、麥克風、記憶、工具授權、桌寵、資料格式都按相關基線回歸。
  mock、真瀏覽器／模型／GPU／平台及真人觀察分開標，不用測試數量抵銷已知失敗。
- 自然度：三組固定情境各錄前後對比，再由使用者評估連續性、角色一致性、主動時機與打擾程度。
  初始目標每項至少 4/5，未達則記具體例；此為規劃門檻，不是已量測成績。
- 逐步發布：純資產／離線預覽 → 隔離組合 → 自主性關閉的新版本 → owner 試用 → 分項啟用。
  不用生產資料測破壞性故障，不在另一台電腦自動更新。
- 回退：資產固定前後版本與 hash；先停活動再切舊資產。程式以可回退 commit／旗標隔離；
  資料格式採相容的新增 migration，不清 DB。停止／drain、備份、隔離還原與舊版讀取驗證完成
  才能聲稱部署回退可用；原始 journal／使用者記憶不能靠回退消失。

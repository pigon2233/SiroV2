# T10 手動驗收操作指南

這些項目需要真人、真裝置或真服務，自動測試無法代替。全部做完並填好結果後，T10-UI-01 才能從 PARTIAL 改成 DONE。

## 開始前

1. 確認這一版已部署：在 Windows 執行 `Start-SIRO.cmd`，等 SIRO 顯示 healthy。
2. 用瀏覽器開正式頁（平常用的 `http://127.0.0.1:8000/`）。按 `Ctrl+Shift+R` 強制重新載入，確保拿到新版。
3. 準備一份**不含私人內容**的測試筆記：在指定工作目錄放一個 `t10-test.md`，內容例如：

   ```
   # 測試清單
   - [ ] 買牛奶
   TODO: 整理桌面
   ```

4. 每項結果填進文末的紀錄表：PASS／FAIL／無法測，再加一句觀察。FAIL 時盡量截圖，並寫下按了什麼、畫面上出現什麼。

> 不要使用真實私人對話或真實記憶。測完可以刪除測試記憶和任務。

---

## A. 真人日常流程（3 輪，每輪約 15 分鐘）

最好請一位**沒看過這份文件細節**的人操作，你只在旁邊看、不提示。三輪可以分不同天做。每輪都完成下面三件事：

**A1. 聊天 → 任務 → 結果 → 回聊天**
1. 在「對話」說一句話，等 SIRO 回覆。
2. 到「任務」，在「要讀取的檔案」輸入 `t10-test.md`，按「建立待審任務（不執行）」。
3. 按「查看任務詳情」，確認範圍正確後按「批准這些檔案的唯讀任務」。
4. 等狀態變成「閱讀完成」，確認看得到「第 2 行：- [ ] 買牛奶」和「第 3 行：TODO: 整理桌面」。
5. 按「返回任務清單」，再回到「對話」。

- 預期：操作者不需要問人就能完成；回到對話時剛才的對話紀錄還在；沒有任何東西被重複執行。

**A2. 記憶：新增 → 搜尋 → 更正 → 刪除**
1. 在對話輸入：`記住：我喜歡喝無糖茶`
2. 到「記憶」，搜尋「無糖茶」，確認看得到這筆記憶，以及它的版本和來源。
3. 按「更正」，改成「我喜歡喝冰的無糖茶」，確認畫面顯示第 2 版。
4. 按「刪除記憶」並確認，這筆記憶從清單消失。

- 預期：每一步都有看得懂的狀態文字。刪除前有確認對話框。

**A3. 設定 → 停止工具**
1. 到「設定」→「權限與停止開關」。
2. 按「電腦與工具操作：已開啟」，頁面重新整理後應顯示「已關閉」。
3. 到「任務」確認無法建立新任務，再回去把開關打開。

- 預期：操作者能自己找到開關，也看得懂現在是開還是關。

**每輪結束請記錄**：完成三件事的時間、卡住的地方、看不懂的字句、有沒有需要你提示的步驟。

## B. 螢幕閱讀器

**Windows（NVDA，免費）**
1. 安裝並啟動 NVDA，用 Chrome 或 Edge 開正式頁。
2. 只用鍵盤：按 `Tab` 一次，應聽到「跳到主要內容」；按 `Enter`，應聽到目前頁面的標題（例如「和 SIRO 聊聊」）。
3. 用 `Tab` 走完「對話」「任務」「記憶」「權限與停止開關」四頁的所有按鈕，每個按鈕都要唸出有意義的名稱，不能只唸「按鈕」。
4. 在任務頁建立任務、在記憶頁搜尋，狀態改變時 NVDA 應自動唸出新狀態（例如「顯示 1 筆符合的記憶」）。

**Linux（Orca，可選）**：在 WSLg 執行 `orca`，用同樣步驟測桌寵視窗。

- 預期：不看螢幕也能完成搜尋記憶和停止工具。

---

## C. 實際縮放與手機

1. 桌面瀏覽器按 `Ctrl` + `+`，放大到 200%。逐頁看一遍：不應出現左右捲軸，按鈕和文字不能被切掉。
2. 再放大到 400%（等於 320px 寬），重複一次。
3. 如果手機和電腦在同一個網路、而且你本來就允許手機連入，用手機直式開一次。沒有這個設定就跳過，**不要為了測試另外開放連線**。
4. 作業系統開「減少動態效果」（Windows：設定 → 協助工具 → 視覺效果 → 動畫效果關閉），重新整理頁面，按鈕不應再有位移動畫。

---

## D. WSLg 桌寵視窗（WebKit 實機）

1. 用 `Start-SIRO.cmd` 啟動，打開桌寵的聊天視窗。
2. 用實體鍵盤打注音，例如「你好」，確認能正常選字，按 Enter 選字時**不會**把訊息送出。
3. 在桌寵或控制頁按 `Tab`，焦點框要看得到。
4. 確認角色上方的文字在深色背景上清楚可讀（本輪修過的對比問題）。

---

## E. 真聲音與真模型

1. 對話頁勾選「播放語音」，問一個需要長一點回答的問題。
2. SIRO 說話時切到「任務」再切回來：聲音應**繼續播放或維持停止**，不能重新從頭播，也不能出現第二個聲音。
3. 說話中按「停止回覆與語音」：聲音和文字都要立刻停住，之後不能再冒出剛才那段回覆的後半段。
4. 開麥克風（權限頁打開「麥克風輸入」），按「開始說話」講一句話，再按「停止並送出」，確認辨識文字合理。
5. 用平常的真模型（Groq 或本機 Ollama）重複第 3 步，確認取消一樣有效。

---

## F. 服務重啟後自動重連（本輪修過）

1. 開著控制頁，在 Windows 重新啟動 SIRO（關掉再執行 `Start-SIRO.cmd`）。
2. 頁面右上角應先顯示「連線中斷 · 點此重新連線」。
3. 服務起來後幾秒內應自動恢復「已連線」，或按一下就恢復，**不需要重新整理頁面**。之前送過的訊息不能被重送。

---

## G. 跨機（只有在你本來就這樣用時才測）

如果你平常會從另一台電腦連到這台的 SIRO：從那台電腦開正式頁，重複 A1 和 F。沒有這種用法就填「不適用」，**不要為了測試開放對外連線**。

## 第二輪重測（2026-10-18 修正後）

第一輪實測時，8000 服務從 10/17 啟動後就沒有重啟過，所以網頁是新的、後端是舊的。修正內容見 [修正報告](../T10-OWNER-FIXES-2026-10-18/REPORT.md)。

0. **先完整重新啟動 SIRO 服務**（關掉後重新執行平常的啟動方式）。瀏覽器按 `Ctrl+Shift+R`。
1. **取消工具**：在對話輸入「請用電腦工具前景執行 sleep 25（不要背景執行），完成後只回答：等待完成」。看到工具卡顯示「執行中…」約 2 秒後，按「停止回覆與語音」。
   - 預期：工具卡在幾秒內變成「已停止：這次工作已取消…」。
   - 不送訊息，觀察 30 秒：不能出現「等待完成」。
   - 按 `Ctrl+R`，再觀察 30 秒：仍然不能出現「等待完成」，也不能播放它的語音。
   - 每次重測請換一個秒數（例如 26、27）：同一個指令被取消過後，系統會刻意要求先確認結果，不會自動再執行。
2. **200% 導覽**：Firefox 放大到 200%。側邊欄應該可以用滑鼠滾輪捲動，「電腦」「技能」「設定」都要點得到。
3. **記憶回答**：新增一筆合成記憶（例如「記住：T10 第二輪，我喜歡烏龍茶」），再問「你的記憶有什麼」。
   - 雲端模型下，她應該說明「雲端模型看不到本機記憶，可到記憶頁查看」，而不是說「沒有記錄」。
   - 她不應說出記憶的內容，因為隱私邊界不變。
4. 若第 1 項仍出現「等待完成」：請記下它是在重新整理前還是後出現、有沒有新的工具卡、語音有沒有播放。若你同意，Claude 可以唯讀查詢那幾筆合成測試對話的執行紀錄來定位原因。

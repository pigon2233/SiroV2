# R03 WoT TD translation spike

日期：2026-09-26｜結果：研究性 PASS（limited spike）

`translate_thing_description` 僅支援 TD 的 title、boolean/number/string/object properties、具名 actions/events，
並轉成既有 T26 descriptor。security declarations、未知 schema 及複雜語意都明確拒絕；沒有引入 ontology server。

此結果表示可用小型 adapter 評估新增設備，而不是宣稱完整 W3C WoT 相容。安全與 transport binding 仍須專屬 adapter。

## 相容矩陣

| TD 欄位 | 狀態 | 轉譯／限制 |
|---|---|---|
| `title` | 支援 | 形成 SIRO device id；仍受既有 id 格式驗證 |
| `properties` | 有限支援 | boolean/number/string/object 與字串 unit；不處理 forms、observable、enum |
| `actions` | 有限支援 | action 名稱；輸入統一標成 `wot.v1`，不解析複雜 input/output schema |
| `events` | 有限支援 | event 名稱；不解析 subscription forms/data schema |
| `security` / `securityDefinitions` | 明確拒絕 | 必須由有 credential policy 的專屬 adapter 處理 |
| `forms`、transport binding | 不支援 | translator 不發網路 request |
| links、context、ontology terms | 不支援 | 不引入 ontology server |

## 新增設備工時比較

本 spike 的共用 translator 為 43 行、contract test 26 行；對只需上述基本 properties/actions/events 的
第二個 TD，新增工作縮小為一份 descriptor fixture 與 transport adapter。相較 T28 Home Assistant 專屬
REST/WebSocket adapter，TD 可省 descriptor 手寫，但認證、transport、readback、重試與安全驗證完全沒有
減少。因此只在已具安全 transport adapter 的設備來源中有小幅整合收益，不能取代專屬 adapter。

採納決策見 `docs/DECISIONS.md` D11：延期產品整合，保留 translator spike。

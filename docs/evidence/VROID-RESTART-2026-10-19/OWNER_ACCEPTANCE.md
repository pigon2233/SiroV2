# 候選模型 siro-restart-separated.vrm 試用與驗收清單

日期：2026-10-24。狀態：**等待 owner 真機目視**。正式模型未動。

## 開啟方式

1. 雙擊桌面 `SIRO-Stop`（確認後端已停；候選啟動器在後端運行中會拒絕）。
2. 執行 `Start-SIRO-VRM-Candidate.cmd`。
3. 測完再 `SIRO-Stop`，之後用 `SIRO-VRM-Start` 回到正式模型。

軟體 GPU 渲染（SwiftShader）已確認：37 個動作可播、髮束 spring 會擺動。以下項目只能在真機 GPU 的實際視窗判斷。

## 第 2 項：外觀（對照 CHARACTER-BRIEF.md 與 reference/）

| 項目 | 已知問題 | 結果 |
|---|---|---|
| 瀏海／髮型 | 瀏海帶預設編髮，與參考有差距 | 待填 |
| 短褲長度 | 偏短；兩次筆觸延長未確認有效 | 待填 |
| 靴底 | 偏厚 | 待填 |
| 身形／髮尾／衣褶 | 尚未逐項貼合參考 | 待填 |
| 內搭、褲襪 | 是身體貼圖，非獨立網格；若要獨立厚度需在 VRoid 重做 | 待填 |
| MToon 實際顏色 | Blender 與軟體渲染只是近似 | 待填 |

修補方法：外觀只能在 VRoid Studio 改（短褲、靴底、瀏海、獨立內搭），改完需重跑 `prepare_candidate.py`、`render_candidate.py`、`bundle_candidate.py`，再重新登記 `candidate-registered/`。此流程要用 GUI 操作 VRoid，開始前需 owner 同意並指定要改的項目。

## 第 4 項：動作與桌寵行為

| 項目 | 檢查點 | 結果 |
|---|---|---|
| 37 個動作 | 逐一看自然度；站立、揮手、坐下起身、走路、鞠躬 | 待填 |
| 揮手 | 手高過頭時是否被窄視窗裁到；手與髮夾、頭髮有無穿插 | 待填 |
| 衣物 | 外套袖子與身體有無穿插；髮束擺動是否自然 | 待填 |
| 情緒／視線／互動 | 開心、難過、生氣表情；視線跟隨；點擊反應 | 待填 |
| 嘴型 | 依音量開合（無音素對應），是否可接受 | 待填 |
| 重啟後完整試用 | 聊天、語音、朗讀、停止 | 待填 |

已知限制：抬手高度受外套破形限制；嘴型沒有音素對應。

# SIRO VRM 角色行為層

renderer 只負責呈現。Core 的 body 協定（`body.emotion`、`body.look`、`body.gesture`、
`body.speech`、`body.cancel`）不變；呈現在 `src/main.js`，可單測的姿勢數學在 `src/procedural.js`。
renderer 不回報給 Core。

## 每幀的層次（由下而上）

1. **動作片段**：`motions/pack.json` 的 idle 循環與一次性片段（mixer）。
2. **保持狀態**：坐下（sit_down → sit_loop → stand_up）、看筆記（notebook_out → notebook_read →
   notebook_away）、被拎起（dangle → land）。保持中其他手勢先等。
3. **生命層**：微動、重心轉移、眼先動頭後跟的視線（smoothDamp）、依情緒改變快慢的呼吸。
4. **程序化動作**（`src/procedural.js`）：可和片段同時存在的加法姿勢。點、伸手用平面雙骨 IK；歪頭、前傾、聳肩、輕點頭、輕搖頭、聽的時候側頭，都是權重，不換掉正在播的片段。強度低於 0.55 的點頭／搖頭只走這層，不再播整段捕捉。SpringBone 仍由每幀 `vrm.update` 負責。
5. **情緒姿態**：依情緒混合權重調整頭的俯仰、側傾、胸口、視線高低、瞥開機率、節奏與眨眼（`STYLE`）。
6. **互動反應**：短暫的表情與姿勢，疊在 Core 的情緒之上，結束後交還。
7. **臉**：表情、眨眼、依實際播放音訊驅動的嘴型（`siro.speech.mouth`），以及片段自帶的表情
   （打哈欠張嘴閉眼、被摸頭閉眼笑、哼歌閉眼等，`GESTURE_FACES`）。

## 情緒

Core 每回合送一次 `body.emotion`（喜悅類→happy；興趣、驚訝、害怕→surprised；悲傷類→sad；
憤怒→angry；不送 relaxed）。

- 換情緒時依強度做一次反應：happy ≥0.6 拍手、≥0.35 點頭；surprised ≥0.6 才嚇一跳
  （一般的「有興趣」只動臉）；sad 嘆氣；angry 不做動作，只有表情與待機姿勢。同一情緒重送不重播。
- 強度 ≥0.45 時改用該情緒的待機循環：`idle_happy`（手背在後、輕彈）、`idle_sad`（垂頭、手在前）、
  `idle_angry`（抱胸、跺腳）。安靜 3 分鐘以上或晚上 10 點後安靜一陣子，用 `idle_relaxed`。
- 2 分鐘沒有新情緒，回到平靜。

## 視線優先順序

1. Core 的 `body.look`（保持 4 秒）。
2. 身體正在做的事：東張西望時眼睛跟著頭走；看筆記時看著筆記。
3. 感興趣的點：滑鼠在她身上移動、使用者正在輸入時的聊天框（頁面送 `siro.view.focus`）。
4. 看著使用者：眼睛對準鏡頭，頭只轉一部分；依情緒調整的瞥視與 3.5° 左右的微跳視。
   開始說話時回到眼神接觸，說話中幾乎不瞥開。

VRoid 預設把 90° 映射到眼球全幅，小角度幾乎看不出眼動，顯得呆滯；載入時把輸入上限調到
水平 28°、垂直 22°（`EYE_RANGE`）。

## 互動

| 操作 | 反應 |
|---|---|
| 滑鼠在她身上移動 | 眼睛（頭跟一部分）看向滑鼠 |
| 在頭上來回撫摸、或點頭 | 摸頭：`pat` 片段，閉眼微笑、頭往手的方向靠 |
| 點身體一下 | 看著你微笑；桌寵模式照舊開啟聊天 |
| 再點一下（2.5 秒內） | 被戳：`poke` 片段，往後一跳，再看向滑鼠 |
| 連續戳到第 4 下 | 嘟嘴生氣並搖頭 |
| 拖曳桌寵視窗 | 被拎起：`dangle` 循環（腳懸空晃）；放下時 `land` |
| 右鍵 | 手勢選單（揮手、鞠躬、坐下、拍手、伸懶腰、哼歌、看筆記……） |

## 說話

依實際播放的音訊開口；重音時小點頭；說話中每 4–7 秒做一個手勢（`talk_offer`、`talk_both`、
`talk_explain`、`talk_self`，不連續重複）；抱胸或手背在後時頻率減半。

回覆可以帶動作 cue。人格提示請模型在句後寫 `[[g:wave]]`、`[[e:happy:0.6]]`、`[[l:chat]]`、
`[[p:lean]]` 這種標記。伺服器在送給聊天與 TTS 之前拿掉，沒有標記時用和下面舊規則同一套的
詞彙後備（一次一個手勢）。cue 走既有的 `body.gesture`／`body.emotion`／`body.look`。
`body.speech` 在這時多一個選填欄位 `motion: "server"`，renderer 就不再用正文猜一次，避免同一句做兩次。
`SIRO_MOTION_CUES=0` 關掉整條：提示不提標記、正文原樣進聊天和 TTS、不另送 cue，renderer 仍用舊的正文規則。
沒有另外呼叫分類模型。

## 聽、讀、想、面向

頁面用 `siro.attention`（`mode`、`side`）告訴 renderer 現在人在做什麼。`side` 是視窗在螢幕上的位置
（左 -1、右 +1）；人多半在視窗的另一側，所以視窗靠右時她的頭略轉向左。

| 狀態 | 她怎麼動 |
|---|---|
| 麥克風正在聽（`正在聆聽`／免手動聽到聲音） | 看向使用者，頭微歪（attentive）。滑鼠在她身上時仍先看滑鼠 |
| 回覆文字出現 | 看一眼聊天框。量得到聊天框就用 `siro.view.focus`；量不到就往左上看，桌寵的對話預設在那 |
| 正在想，或工具還沒回來 | 輕微的思考姿勢，不打斷待機 |
| 正在查資料（`browser.*`、`claude.ask`） | Core 送 `body.gesture` `notebook`，她拿出筆記；片段還沒開始時先用前傾與思考姿勢 |

## 音效

`src/sfx.js` 以 WebAudio 合成輕柔音效（無音檔、無授權問題）：拍手三拍、被戳「波」、摸頭沙沙＋輕笑、
落地、坐下衣料聲、翻筆記。總音量 0.3，23–08 點減半。說話中（嘴型訊號或 `siro.audio.busy`，
由主頁在播放語音／麥克風錄音時每秒送出）一律靜音；自己做的小事（閒置）每 10 分鐘最多一次、夜間不出聲；
輕笑 30 秒最多一次。右鍵選單「音效：開/關」，狀態存 localStorage `siro.sfx`。

## 沒人理的時候

安靜 20 秒起，每 20–60 秒挑一件小事：整理頭髮、哼歌、東張西望、伸懶腰、看一會兒筆記；
深夜（23–5 點）較常打哈欠。安靜 4 分鐘後會自己坐下。有人回來（Core 訊息、說話、滑鼠）
就停下或站起來。

## 散步（桌寵模式）

右鍵「散步」或閒置時偶爾：她先問桌寵視窗有多少空間（往空間大的一邊），用小碎步轉身 90°，
起步、走、停步，再轉回來面向你。走路時視窗以她的步速移動（1.26 m/s × 0.7），起步與停步的加減速
和步幅混合同一條曲線，腳不會滑。視窗不會走出螢幕工作區。說話、Core 訊息、點她都會叫住她；
拖曳交給「被拎起」；聊天開著時不走。沒有原生視窗（一般網頁）時不散步。
訊息：renderer → 頁面 `siro.desktop.walk`（start／stop）、頁面 → renderer `siro.desktop.walk.state`；
頁面 → 原生 `desktop.walk`／`desktop.walk.stop`。步速數學在 `desktop/wander.mjs`。

## 取景

載入時把每個片段取樣一次，記下手與頭能到的最高點，鏡頭保證這個高度在畫面內，揮手、伸懶腰
不會被切掉。只保留高度不保留寬度：手臂往兩側甩只有一瞬間，為此縮小角色不划算。桌寵窗格加高到
360×640（透明區域不攔滑鼠），角色大小幾乎不變。

## 接下來可做

聽、回覆時看聊天框、查資料拿筆記、依視窗在螢幕上的位置轉頭，都已接到現有的頁面狀態與 body 協定。
IK 是平面上的兩根骨頭，不是全身求解；點與伸手的方向是固定的幾種，不是任意三維目標。
模型沒寫標記時只靠詞彙後備，不另外呼叫 Groq 或本機分類器。

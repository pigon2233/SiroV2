# SIRO VRM 角色行為層

renderer 只負責呈現。Core 的 body 協定（`body.emotion`、`body.look`、`body.gesture`、
`body.speech`、`body.cancel`）不變；以下行為都在 `src/main.js` 內完成，不回報給 Core。

## 每幀的層次（由下而上）

1. **動作片段**：`motions/pack.json` 的 idle 循環與一次性手勢（mixer）。
   情緒持續時，若 pack 有 `idle_<情緒>`（例如 `idle_sad`）就換成那個循環，沒有就用 `idle`。
2. **生命層**：呼吸外的微動、重心轉移、眼先動頭後跟的視線（smoothDamp）。
3. **情緒姿態**：依情緒混合權重調整頭的俯仰、側傾、胸口下沉、視線高低、
   瞥開的機率、動作節奏與眨眼頻率（`STYLE` 表）。
4. **互動反應**：短暫的表情與姿勢，疊在 Core 的情緒之上，結束後自動交還。
5. **臉**：表情權重、眨眼、依實際播放音訊驅動的嘴型（`siro.speech.mouth`）。

## 視線優先順序

1. Core 的 `body.look`（保持 4 秒）。
2. 她感興趣的點：滑鼠在她身上移動（1.2 秒）、使用者正在輸入時的聊天框
   （頁面送 `siro.view.focus`）。
3. 看著使用者：眼睛對準鏡頭，頭只轉一部分（頭整個低向鏡頭會像在看地板）；
   加上依情緒調整的瞥視與 3.5° 左右的微跳視（saccade）。
4. 開始說話時中斷瞥視，回到眼神接觸；說話中幾乎不瞥開。

VRoid 預設把 90° 映射到眼球全幅，所以小角度幾乎看不出眼動，顯得呆滯；
載入時把輸入上限調到水平 28°、垂直 22°（`EYE_RANGE`）。

## 互動

| 操作 | 反應 |
|---|---|
| 滑鼠在她身上移動 | 眼睛（頭跟一部分）看向滑鼠 |
| 在頭上來回撫摸 | 摸頭：閉眼微笑、頭往手的方向靠 |
| 點一下 | 看著你、微笑；桌寵模式照舊開啟聊天 |
| 連續戳 4 次 | 嘟嘴生氣並搖頭 |
| 拖曳桌寵視窗 | 嚇一跳、聳肩往下看 |
| 右鍵 | 手勢選單（揮手、鞠躬、坐下……） |
| 很久沒人理（45 秒起） | 東張西望；pack 有的話伸懶腰、深夜打哈欠；4 分鐘後自己坐下，有人回來就站起來 |

## 取景

載入時把每個片段取樣一次，記下手與頭能到的最高、最寬範圍；鏡頭保證這個範圍在畫面內，
揮手不會被視窗切掉。桌寵窗格因此加高到 360×640（透明區域不攔滑鼠），角色大小幾乎不變。

## 接下來可做

- 聽：使用者用麥克風說話時看向使用者並微歪頭（頁面已知道錄音狀態，可比照 `siro.view.focus` 送出）。
- 讀：SIRO 的文字回覆出現在聊天框時看一眼。
- 情緒專屬片段：`idle_happy`／`idle_sad`／`idle_angry`／`idle_relaxed` 與 `clap`、`sigh`、
  `stretch`、`yawn`；renderer 已接好，pack 補上片段即生效。
- 依螢幕位置決定「使用者在哪個方向」（桌寵通常在螢幕右下，使用者在左上方）。
